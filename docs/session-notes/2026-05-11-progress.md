- 公开页面暂不直接套完整模板源码，优先借鉴主题视觉语言，避免破坏现有 API/React 状态结构。

  - 原因：更适合“声优资料库/目录站”，比纯 dashboard 更适合公开展示。

- Eventernote 逻辑先做 provider 边界，后续再强化真实抓取、缓存和解析。
